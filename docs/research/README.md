# Research and working notes

Working material behind the engagement-readiness auditor, kept for traceability. The code and
`docs/engagement-design.md` / `docs/engagement-kpi.md` are the source of truth; these files record how the
decisions were reached and may describe intermediate states.

| File | Content |
| --- | --- |
| `research-performance-elements-friction.md` | Performance, element availability and interaction friction metrics, with sources |
| `research-psychology-indices.md` | Psychological / persuasion / trust / dark-pattern constructs and composite index design, with sources |
| `approved-plan.md` | The approved plan (Italian) |
| `architecture-plan-fable.md` | Original architecture (transport, collectors, MCP/plugin, scoring, workstreams) |
| `CONTRACTS.md` | Module contracts and coordinator decisions between workstreams |
| `owed-notes.md` | Items owed between workstreams during review rounds |
| `jev-roles-decision.md` | User decision: Jev navigates and judges, Claude for perception judgments, reuse the original loop |
| `jev-roles-design-fable.md` | Design of Jev as judge, default pilot and crawler fallback |
| `typesafe-api.md` | TypeSafe API facts and limits used by that design |
| `codebase-map.md` | Map of the original Jev Ultrafast code before the fork changes |
| `jev-code-survey.md` | Code survey that fed the Jev-roles design |
| `ws2-round3-pending.md`, `ws3-round3-review.md` | Review findings and rulings carried across a container restart |
| `workflows/` | Multi-agent workflow scripts used to build and review each phase, and the saved results of the Jev-roles phase (`phase-e-state.json`) |
| `STATUS.md` | Where the work stands and the next steps |
